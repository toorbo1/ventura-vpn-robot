# Изменения в боте VenturaVPN (ventura-vpn-robot)

## Что было добавлено

### 1. Функции проверки подписки

- `format_subscription_end_date(expires_timestamp)` - форматирует timestamp в читаемую дату
- `get_subscription_details(uid)` - возвращает полную информацию о подписке пользователя:
  - active - активна ли подписка
  - has_sub - есть ли подписка вообще
  - days_left - сколько дней осталось
  - max_devices - максимальное количество устройств
  - end_date_str - дата окончания в формате "5 сентября 2026"

### 3. Обновленные обработчики

- `/start` - проверяет статус подписки и показывает соответствующее сообщение
- `back_main` - кнопка возврата в главное меню также учитывает статус подписки

## Как это работает

1. При команде /start бот вызывает `get_subscription_details()` для проверки статуса
2. Если подписка активна (`has_sub=True`) - показывается ACTIVE_SUBSCRIPTION_MSG с деталями
3. Если подписки нет или она истекла - показывается NO_SUBSCRIPTION_MSG
4. Кнопка "Назад" (back_main) также обновляет сообщение в зависимости от статуса

## Тестирование

Для тестирования разных сценариев:

1. **Без подписки**: запустите бота `/start` как новый пользователь
2. **С подпиской**: оформите подписку через панель управления, затем нажмите `/start`
3. **С истекшей подпиской**: подождите окончания тестового периода

## Следующие шаги

```bash
cd /opt/ventura-vpn-robot
git pull origin main

```
