## Проблема:
GitHub Actions не может подключиться к серверу 150.241.66.53 по SSH — соединение зависает или таймаутится.

## Как сделать деплой вручную:

### Вариант 1: Через Beget панель управления
1. Зайди в панель управления сервером Beget
2. Открой файловый менеджер
3. Перейди в `/root/bot/`
4. Загрузи новый `bot.py` через веб-интерфейс
5. Перезапусти бота через панель или терминал

### Вариант 2: Через SSH (если есть доступ)
```bash
# С локального компьютера (Windows):
scp bot.py root@150.241.66.53:/root/bot/bot.py
ssh root@150.241.66.53 "pm2 restart ventura-bot"
```

### Вариант 3: Через терминал на сервере
1. Подключись к серверу по SSH
2. Перейди в директорию проекта: `cd /opt/ventura-vpn-robot`
3. Скопируй новый файл: `cp ~/Downloads/bot.py /root/bot/bot.py`
4. Перезапусти: `pm2 restart ventura-bot`

## Проверка после деплоя:
1. Открой бота @VenturaVpnRobot
2. Нажми /start
3. Должно появиться новое сообщение Каролины со стикером
4. Кнопки должны быть: "Подписка", "Тест-драйв VPN", "Есть код?", "зови друзей", и т.д.

## Если что-то сломалось:
Бекап старой версии находится в `/root/bot/backups/`
