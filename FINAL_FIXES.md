## Проблема 1: Тестовый пользователь видел обычные сообщения
**Причина:** В функции `do_buy` не было проверки на тестового пользователя

**Решение:**
- Добавлена проверка `is_test_user = (uid_raw == TEST_USER_ID)`
- Для тестового пользователя используется `safe_edit` вместо `sendMessage`
- Передается message в функцию для редактирования

## Проблема 2: Сообщения не редактировались при нажатии кнопок
**Причина:** Использовался `sendMessage` вместо `safe_edit`

**Решение:**
- Обновлены все callback обработчики админ панели
- Кнопка "buy" теперь передает message в do_buy
- Все кнопки используют safe_edit для редактирования сообщений
